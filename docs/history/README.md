# History

For developers who want to know why the code is the way it is.

These are the design documents (`*-design.md`) and the implementation plans that produced the code: v1 (the read-only server) and local models (`tgmcp ask`, `tgmcp bench`).
They are kept as history and are not updated; where they differ from the code, the code and the other pages under `docs/` are right.
Paths inside them refer to the old `docs/superpowers/` folder, where they used to live.
